# SteamCounter 1.0.0

The first stable release: a lightweight native Windows app for Steam player counts, charts and historical averages.

Download **SteamCounter-1.0.0-windows-x64.exe** below and run it. This is a single portable desktop executable, with no installer or ZIP package. No account, API key or embedded browser is required.

## Features

- Search by game name or Steam AppID.
- Current player counts from Steam, with daily and weekly estimates and monthly/yearly averages from SteamCharts.
- Real 48-hour, weekly, monthly and yearly charts. Gaps stay visible; averages are never substituted with peaks.
- Optional local history cache to reduce repeat requests; no background collection service.
- Steam-inspired interface, point-anchored chart tooltips and centered search text.
- English UI and documentation. The CLI remains available to build from source.
- Home shortcuts become Last after a successful search, with the three most recent games saved across restarts. Demo mode is removed from the release app.

These are concurrent-player statistics. Estimated values, incomplete periods and cached/stale data are labeled. History availability depends on the provider. Windows x64 is the tested platform; the executable is unsigned.
