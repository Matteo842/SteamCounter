# SteamCounter 1.1

SteamCounter 1.1 makes finding the right game faster and gives the dashboard a cleaner, more visual header.

Download **SteamCounter-1.1-windows-x64.exe** below and run it. This is a single portable desktop executable, with no installer or ZIP package. No account, API key or embedded browser is required.

## What's new

- Live search suggestions appear after a short pause while typing; pressing Enter still starts a normal search.
- Search results are limited to standalone games. DLC, demos, soundtracks and other non-game AppIDs are filtered using Steam Store metadata.
- The selected game's official Steam banner now appears at the top left of the dashboard, with the SteamCounter brand centered.
- The separate Search button has been removed and the search field now includes an Enter-key hint.
- Settings now uses a compact square gear button.
- Autocomplete requests are debounced, limited to one at a time and cached for the current session, together with AppID type checks.

These are concurrent-player statistics. Estimated values, incomplete periods and cached/stale data are labeled. History availability depends on the provider. Windows x64 is the tested platform; the executable is unsigned.
